# Expense Tracker

A simple expense tracker that lets you log spending by category and view totals.

## Features

- Add expenses with description, amount, and category
- View all expenses
- Show total spending
- Breakdown by category
- Delete individual expenses
- Available as both a Python script and a web tool

## How to Use (Python)

1. Run the script
2. Choose an option from the menu
3. Add, view, or delete expenses
4. View total spending and category breakdown

## Categories Included

- Food
- Transport
- Entertainment
- Bills
- Other

- Python version of the tracker
